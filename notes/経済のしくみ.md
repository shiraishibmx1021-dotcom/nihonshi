# 経済のしくみの説明メモ（ユーザー提供の対話録をもとに、事実を直したもの）

授業で経済を説明するときの比喩と筋道。ユーザーが「わかりやすい」と感じた形なので、近代の経済史の授業で使う。
**元の資料には事実とずれる部分があったので、下の「注意」を守ること。**

## 1. 投機とバブル（近代〈恐慌の時代〉授業01で使用済み）
- 実需（本当に使う人）だけなら値段は暴れない。「買って高く売ればもうかる」人が集まると、量は同じなのに買い手が増えて値段がふくらむ。
- 比喩：5万席のドーム公演のチケットを10万人が取り合う → 転売価格がつり上がる。
- 破裂：実需が消えると、全員がいっせいに売る側に回る → 買い手がいないので、上がったとき以上の速さで落ちる。株価の暴落も同じ。株の発行数は決まっていて、「持っている人から譲ってもらう」しかないので奪い合いになる。

## 2. 米の経済と資本主義（明治の産業革命の授業で使う。まだ未使用）
- 江戸：富の中心は土地と米。耕地には限りがあり、米は食べれば消え、長く貯めると傷む。年貢米は武士が消費して終わることが多い。
- 近代：富の中心はお金（資本）。お金は使っても人から人へ移るだけで消えない。腐らないので銀行に大きく貯められ、利益を新しい工場・機械に**再投資**できる → 生産が雪だるま式に拡大する。
- 付加価値：原料に技術で価値を乗せて高く売る。機械を使えば、土地や人手の限界をこえて生産を増やせる。
- **注意**：江戸にも貨幣経済・両替商・新田開発による成長はあった（近世⑤）。「江戸＝ゼロサム、明治＝プラスサム」は言い切らず、「成長の天井の高さが違う」くらいに書く。

## 3. お金は信用でできている（授業06で使用済み）
- 紙幣はそれ自体はただの紙。使い道がないからこそ、信用さえあれば何とでも交換できる万能の道具になる。
- 金本位制＝「いつでも金と交換できる」約束で信用を支える。管理通貨制度＝金ではなく、政府・日本銀行への信用だけで支える（テーマ史：貨幣史 授業11）。

## 4. 為替と金の流出（授業03・07で使用済み）
- 貿易の代金は、ふつう金を船で運ばず、銀行どうしの帳簿で売りと買いを差し引き（相殺）する＝為替。
- 差し引けない差額（輸入超過の分）は、金本位制のもとでは最後に金（正貨）で払う → 金が国外へ流出する。
- **注意（元の資料のまちがい）**
  - 「関税自主権がないから輸入超過」は1920年代には当てはまらない。関税自主権は1911年に回復している。輸入超過の原因は、大戦後に欧米の製品が戻り、日本の重化学工業が競争に負けたこと。
  - 1917〜1930年は金輸出禁止の期間なので、金は出ていけない。この期間は、金のかわりに**為替相場が揺れて下がる**形で表れる。金が実際に大量に流出したのは、1930年の金解禁のあと（昭和恐慌）と、明治の金本位制の時期。
  - 「ロンドンの銀行が金を持ってこいと迫った」のような場面は、比喩としてはよいが、史実として書かない。

## 5. 手形・割引・モラルハザード（授業01で使用済み）
- 手形＝「○月○日に払います」という約束の紙。銀行が期日前に手数料を引いて現金化する（割引）。
- 震災手形の制度は、震災と関係なく投機的経営に失敗した企業の手形まで紛れこむ抜け道になった（教科書の記述）。助けてもらえる制度に便乗して、自分の失敗まで救ってもらおうとすること＝モラルハザード。
- **注意**：「鈴木商店と台湾銀行が結託して震災のせいだと偽った」とまでは断定しない。教科書は「大口債務者には投機的経営に失敗した企業が含まれていた」と書く。台湾銀行は、鈴木商店への巨額の不良債権を抱えていた。
