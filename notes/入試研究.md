# 入試研究ノート ── 何が問われるか、だから授業に何を入れるか

2026年10月時点。予備校の講評・解説記事（検索で読めた範囲）と、過去の入試問題の知識をもとにまとめた。
**予備校ページの本文はネットワーク設定で開けず、検索結果の要約から拾った情報が多い。** 年度ごとの大問テーマは、記事によって食い違うことがある。正確な問題は赤本・代ゼミの問題PDFで確かめること。

---

## 1. 試験ごとの特徴

### 慶應義塾大学 商学部（A方式・日本史100点・60分）

- **形式**：大問3題。各大問はA4で1〜1.5枚ほどのリード文に、空欄が20個前後。語群（数字つきの大量の語句）から選ぶ空欄補充と、語句の記述が中心。短い論述（10〜60字程度）が1〜2問。
- **時代**：近現代が多めだが、古代〜戦後まで全時代から出る。1つの大問が原始〜近代を横断することもある（2025年の大問1「東アジアと日本社会」など）。
- **テーマ**：**経済・産業・流通・貿易・対外関係・社会**が中心。労働史・銀行史のように、ふつうの大学では大問にならないテーマ史も出る。
- **年度ごとの大問（記事による。要確認）**
  - 2026：古代〜室町の支配体制の変遷／江戸初期〜幕末の対外関係／明治以降のマスメディアと社会
  - 2025：原始〜近代の東アジアと日本社会／江戸時代の流通と経済（論述は法令の趣旨＝物流の独占と価格つり上げ）／オリンピックからみた近現代
  - 2024：原始〜近世の文化の伝播／江戸〜明治の学問・思想・技術／戦中・戦後の政治とエネルギー問題
  - 2023：鎌倉仏教／古代〜近世の貨幣史／戦後〜現代の日米関係
  - 2022：古代〜現代の文化・芸能史／江戸の儒学／明治〜昭和初期の政治史
  - それ以前：幕末〜明治の貿易と産業（2014）、近代の産業・経済史（2020）、大戦間期の貿易と銀行（2021）
- **教科書との関係**：2025年の正解の約95%が山川『詳説日本史』に載っている、という分析がある。**教科書の本文・注・図版説明の細かい語句**まで問われる（2026年の帥升・後漢書東夷伝・高向玄理・南淵請安・旻・入唐求法巡礼行記など）。
- **資料の読み取り**（グラフ・統計）は少ない、という見方が多い。ただし**数字そのもの**（年号、石高、貿易の割合、金の含有量の変化など）は語群の選択肢として問われる。
- **地図**：語群の中で場所を問う（港・鉱山・産地・城下町など）。地図そのものを読ませる問題は多くないが、**場所がわかっていないと語群から選べない**。

### 明治大学 商学部（60分）

- 大問4題。マーク（5択・年代や人物・語句・数値を選ぶ）と記述が半々ほど。
- **4題のうち1題はテーマ史**（女性史・土地制度史・商業史・流通史・貨幣史・交通史など）。**社会経済史と文化史**が厚い。
- 近現代が半分近く。史料問題が頻出。年代整序や、史料を年代順に並べる問題もある。

### 明治大学 経営学部（60分）

- 大問3題、解答50個ほど。ほぼマークの4択、記述が2〜3個。論述はほとんどない。
- **近現代の比重が高い**（全問が近現代の年もあった）。社会・経済史が目立つ。
- **史料問題が毎年**。教科書にない初見史料も出る（例：殖産興業の建議書、台湾銀行の破綻の史料）。
- 正誤問題はやや難で、消去法だけでは解けないものがある。似た人名・業績の区別が要る。

### 大学入学共通テスト（歴史総合・日本史探究）

- 大問6題（第1問＝歴史総合、第2問＝テーマ史、第3〜6問＝原始古代・中世・近世・近現代）。
- **資料を使う設問がほとんど**：史料・図版（絵画・写真）・略系図・**地図**・**グラフ**・**統計表**・年表・生徒のメモやパネル。
  - 2025：第1問「歴史上の境界」は地図と国際秩序を結びつける問題。第5問「近世の村」は教科書に載っている形のグラフ。第6問は松本清張の年譜から近現代を読む。
  - 2026：第1問「災害の歴史」（図・表・地図・グラフ・年表。関東大震災の各国からの支援額のグラフなど）。地引網漁を描いた絵、近世の城郭なども出た。
- 年代整序は減り（2026は1問）、**組み合わせ（2つの文の正誤×資料の読み取り）**が増えた。
- 「何世紀に何が起きたか」の時期の把握と、**なぜそうなったかの理解**がないと解けない。用語の暗記だけでは足りない。

### 早稲田大学 商学部（参考）

- 大問6題、正誤判定が多い。史料問題は頻出で、初見史料も出る。第6問は戦後の経済（金融・産業）が多い。

## 2. まとめると、何が問われるか

| 問われ方 | 主に出す試験 | 授業でやること |
|---|---|---|
| 細かい語句（教科書の注・図版説明まで） | 慶應商・明治 | `kw` と一問一答で拾う。教科書を全ページ読んでから書く |
| **場所**（遺跡・都・城柵・港・鉱山・産地・街道・戦場・開港地） | 共通テスト・慶應商（語群）・明治 | **地図**を授業の中に入れる |
| **数字の変化**（貿易・生産・人口・金の含有量・米価・石高） | 共通テスト（グラフ・表）・慶應商（語群の数値） | **グラフ・表**を入れて、「なぜ増えた／減ったか」を書く |
| 人のつながり（外戚・婚姻・将軍の継承） | 共通テスト（略系図）・各大学 | **系図**を入れる |
| 史料（有名史料＋初見史料） | 明治・早稲田・共通テスト | 史料の目印になる言葉を「入試ではこう出る」に書く |
| 時代をこえたテーマ（貨幣・流通・土地制度・対外関係・女性・労働） | 慶應商・明治商・共通テスト第2問 | 伏線の回収（`R()`）でテーマをつなぐ。テーマ史セットを作る |
| 作品・建物の見分け（写真） | 共通テスト・各大学 | 「どこを見れば一目でわかるか」を文章で書く |
| 正誤・組み合わせ（似た用語の区別） | 全部 | ひっかけの誤文を「入試ではこう出る」に書く |

## 3. 授業に入れる図・地図の一覧（優先順）

### 地図（日本の白地図 `jmap` で作れるもの）

- 古代①：旧石器・縄文の遺跡／弥生の遺跡／古墳（大仙陵・誉田御廟山・造山・稲荷山・江田船山・岩戸山）
- 古代②：白村江のあとの防衛（水城・大野城・基肄城・高安城・大宰府）と都の移り変わり
- 古代③④：城柵（渟足柵・磐舟柵・多賀城・秋田城・胆沢城・志波城）
- 古代⑤：承平・天慶の乱、刀伊の入寇
- 中世①：前九年・後三年合戦、日宋貿易（大輪田泊・厳島・博多）
- 中世③：モンゴル襲来（博多湾・対馬・壱岐・鷹島）
- 中世④：南北朝（吉野・湊川など）、日明貿易の港
- 中世⑤：一揆（正長・播磨・山城・加賀）、港町・門前町・寺内町
- 中世⑥：戦国大名の分布
- 近世①：銀山と鉄砲伝来、信長・秀吉の戦い
- 近世②：関ヶ原・大坂の陣、島原・天草一揆
- 近世③：平戸・長崎・四つの窓口
- 近世⑤：五街道と関所、東廻り・西廻り海運、諸産業の特産地、三都
- 以降：開港地（幕末）、自由民権運動の激化事件、日清・日露戦争、など

### グラフ・表（数字を確かめてから入れる）

- 江戸の貨幣改鋳（小判の金の含有量の変化）
- 幕末の貿易（輸出入品の割合、横浜の割合）
- 近代の産業（生糸・綿糸の生産と輸出入）
- 戦後の経済成長率、など
- **数字は教科書・史料集で確かめられたものだけを使う。** あいまいな数字のグラフは入れない。

### 東アジアの地図（白地図がまだない）

- 朝鮮半島・中国大陸を含む地図（白村江、遣唐使の航路、モンゴル襲来、勘合貿易、朱印船貿易、日清・日露戦争）は、今の白地図（日本のみ）では作れない。東アジアの白地図を用意してから作る。
